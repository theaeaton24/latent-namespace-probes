# DialoGPT response review

The user shared six generated responses from the initial prompt-family check. The outputs mostly reformulated the input rather than completing the requested supportive task. One repeated the textual request for a symbol without producing the symbol. Two used repeated apologies. This strongly limits the suitability of this model for testing compliance with conversational instructions. The absence of emoji symbols does not demonstrate a learned no-emoji policy.

The scientific next step is to verify baseline instruction-following before proceeding; alternatively start with Qwen and create a positive style checkpoint to establish measurable symbol usage before splitting into the bare-rule and rationale training conditions.
